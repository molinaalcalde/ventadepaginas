# KINETIC — Web de Alto Rendimiento y Gestión Comercial

Landing page y sistema CRM para negocios locales.

## Stack

- **Next.js 16** (App Router + TypeScript)
- **Tailwind CSS v4**
- **Supabase** (Auth + Database + CRM)
- **Vercel** (Deploy)

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).
